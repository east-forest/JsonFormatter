# 要件定義書

## アプリケーションの目的

- JSONデータをブラウザ上で簡単に整形・検証できるツールである。主な目的は以下の３点。
- JSONデータを読みやすい形に整形する
- JSONデータが正しい形式であるか検証する
- 整形したJSONデータを簡単にコピーできるようにする

## 機能要件

### 基本機能

| 機能ID | 機能名     | 機能概要                                   |
| ------ | ---------- | ------------------------------------------ |
| F-001  | JSON整形   | JSONデータを読みやすい形に整形する         |
| F-002  | JSON検証   | 入力されたデータが正しいJSON形式か検証する |
| F-003  | 結果コピー | 整形結果をクリップボードにコピーする       |
| F-004  | リセット   | 入力欄・出力欄を空にする                   |

### 機能概要

#### F-001 JSON整形

- 入力されたデータを読み取る
- 正しい場合、読みやすい形式に整形する
- 整形結果を出力欄に表示する
- インデントの幅は半角スペース2個とする
- 不正なJSONは整形せずにエラーを表示する
- 空の場合はボタンは非活性とする

#### F-002 JSON検証

- 入力された文字列が有効なJSONか判断する
- 正しい場合はF-001の処理を実行する
- 不正な場合は失敗メッセージを表示する

#### F-003 結果のコピー

- 「Copy」ボタンを押下することで、整形結果をコピーする
- 出力結果が空の場合は、コピーボタンを押下できないようにする

#### F-004 入力・結果のクリア

- 「Clear」ボタンを押下することで、入力欄・出力欄や表示されているメッセージを空にする

#### 追加検討中...

- JSON圧縮
- JSON → CSV変換
- CSV → JSON
- JSONファイルの読み込み
- JSONファイルの出力
- インデント幅の変更

## 非機能要件

- PCブラウザ上でのみ稼働（Chrome, Edge利用可能）
- 入力データを外部サーバーへ送信しないこと（セキュリティ）
- 入力欄と出力欄を同一画面に配置し、画面遷移を伴わずに操作できること。（使用性）
- Formatボタン押下後、3秒以内にJSONの検証および整形処理が完了すること。
